# orgmd 0.5.0 release and deployment checklist

This checklist records work still required after the repository's
release-ready reference implementation has been reviewed. Completing this
file is a maintainer operation; it does not claim that npm, GitHub Releases,
or Pages have already been updated.

- [ ] CI green on the release commit
- [ ] role.editor ratifies the DEC-0003 lifecycle migration in review
- [ ] npm pack tarball inspected and smoke-tested
- [ ] npm owner explicitly runs npm publish from the reviewed tag
- [ ] version tag and GitHub release created by a maintainer
- [ ] main contains the site changes and Pages workflow succeeds
- [ ] published npm package smoke-tested with npx orgmd --version
