# ORG.md (the project)

**Mission:** an open, portable specification for the small set of
organisational meanings, decisions, constraints and ownership relationships
that humans and AI systems must interpret consistently.

**Tone:** plain, direct, no marketing. RFC 2119 keywords in normative text.

**How we govern:** with this bundle. See GOVERNANCE.md and `decisions/`.
