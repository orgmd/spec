**DEC-0008 — Entry identity is bundle-scoped.** `id` is unique within its
bundle; the pair (bundle, id) is unique in the tree. The same id in
another bundle on a resolution path denotes the same entry, overridden or
narrowed per SPEC §5, and entries sharing an id must be the same kind.
Accepts RFC 0001, resolving issue #1.
