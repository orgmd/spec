**DEC-0017 — Contested blocks by reliance only.** Agents are blocked only
where a relied-upon entry is contested; marking is visible everywhere but
is not propagation. Only the owner or its escalation path may set
contested, and transitions are attributable. Accepts RFC 0010, resolving
issue #12.
