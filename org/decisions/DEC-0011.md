**DEC-0011 — Resolution runs over a designated path.** The hierarchy may
be a DAG; resolution is over exactly one designated, ordered,
duplicate-free path per consumer, held in resolver configuration. Every
effective context carries a context identifier (SPEC §5.5), so path
changes are detectable. Accepts RFC 0004, resolving issue #14.
